# Guía Completa: Slides Educativos para Nodo360
## Cómo crear slides de alta calidad para tus cursos

---

## 1. Herramienta y Setup Inicial

### Google Slides — Configuración
- **Formato:** 16:9 (1920x1080) — estándar para web
- **Fuente principal:** Inter, Montserrat o Poppins (modernas, legibles)
- **Fuente títulos:** La misma en bold o una sans-serif con más peso
- **Tamaño mínimo de texto:** 18px (nada más pequeño o no se lee en móvil)

### Paleta de colores Nodo360
Usa colores consistentes con tu marca:

| Uso | Color | Hex |
|-----|-------|-----|
| Fondo principal | Azul oscuro/negro | #070a10 o #0f1419 |
| Fondo alternativo | Gris muy oscuro | #1a1f2e |
| Texto principal | Blanco | #FFFFFF |
| Texto secundario | Gris claro | #9ca3af |
| Acento Bitcoin | Naranja | #f7931a |
| Acento secundario | Naranja claro | #ff6b35 |
| Éxito/correcto | Verde | #22c55e |
| Error/peligro | Rojo | #ef4444 |
| Info/neutro | Azul | #3b82f6 |

### Crear tu plantilla base
Antes de hacer 114 slides, crea una plantilla con estos layouts:
1. **Portada** — título del curso + módulo
2. **Título de sección** — para abrir cada lección
3. **Contenido simple** — título + texto (2-3 bullets máximo)
4. **Comparativa** — dos columnas (Hot vs Cold, Pros vs Contras)
5. **Diagrama/flujo** — para procesos paso a paso
6. **Lista con iconos** — cada punto con icono visual
7. **Dato destacado** — número o frase central grande
8. **Cierre** — resumen o CTA para siguiente lección

Con 8 layouts preparados, cada slide nuevo es solo rellenar contenido.

## 2. Principios de Diseño Educativo

### La regla de oro: Una idea por slide
- Cada slide comunica UN solo concepto
- Si necesitas explicar dos cosas, usa dos slides
- El alumno debe entender el slide en 5 segundos

### Menos texto, más visual
```
❌ MALO:
"Un hardware wallet es un dispositivo físico diseñado 
específicamente para firmar transacciones de Bitcoin sin 
exponer tus claves privadas a internet. Las claves se 
generan dentro del dispositivo y nunca salen de él."

✅ BUENO:
Título: Hardware Wallet
Icono de dispositivo + candado
→ Genera claves dentro del dispositivo
→ Firma transacciones internamente  
→ Las claves NUNCA salen
```

### Jerarquía visual
1. **Título** — lo primero que se lee (grande, bold, arriba)
2. **Elemento visual** — icono, diagrama o imagen (centro)
3. **Puntos clave** — máximo 3 bullets (cortos, debajo)
4. **Nota/contexto** — texto pequeño opcional (abajo)

### Contraste y legibilidad
- Fondo oscuro + texto claro (alineado con la estética Nodo360)
- Naranja (#f7931a) solo para destacar palabras clave, no para párrafos
- Nunca texto claro sobre fondo claro ni oscuro sobre oscuro

## 4. Elementos Visuales

### Iconos (gratis)
- **Lucide Icons** (lucide.dev) — los mismos que usas en Nodo360
- **Flaticon** (flaticon.com) — iconos más elaborados, gratis con atribución
- **Google Material Icons** (fonts.google.com/icons)
- **Phosphor Icons** (phosphoricons.com) — estilo limpio

### Diagramas
- Usa las formas nativas de Google Slides para diagramas simples
- Flechas, cajas redondeadas, círculos con números
- Mantén colores consistentes con tu paleta

### Imágenes
- NO uses fotos genéricas de stock (se ven baratas)
- SÍ usa: iconos, diagramas propios, capturas de pantalla reales, ilustraciones simples
- Si necesitas ilustraciones: unDraw (undraw.co) tiene SVGs gratuitos editables

### Emojis como iconos rápidos
Cuando no tengas tiempo de buscar iconos, los emojis funcionan bien en slides educativos:
- 🔒 Seguridad
- ⚡ Lightning/rápido
- 🔑 Claves
- ❌ Error/no hacer
- ✅ Correcto/hacer
- ⚠️ Advertencia
- 💡 Consejo
- 🎯 Objetivo
- 📱 Dispositivo
- 🖥️ Ordenador
- 🔗 Blockchain/conexión

## 5. Flujo de Producción Optimizado

### Estrategia: Lotes, no slide por slide

```
FASE 1 — Plantilla (1-2 horas, una sola vez)
├── Crear los 8 layouts base
├── Definir paleta, fuentes, tamaños
├── Crear slide maestro en Google Slides
└── Duplicar para cada curso

FASE 2 — Estructura (30 min por curso)
├── Crear todos los slides vacíos con títulos
├── Asignar layout a cada slide según el guión
└── Resultado: esqueleto completo del curso

FASE 3 — Contenido (3-4 horas por curso)
├── Rellenar texto slide por slide
├── Seguir el guión del documento .md
├── No perfeccionar — solo meter contenido
└── Resultado: curso funcional

FASE 4 — Pulido (1-2 horas por curso)
├── Ajustar alineación
├── Añadir iconos/diagramas donde falten
├── Revisar consistencia visual
└── Resultado: curso profesional
```

### Tiempo total estimado
| Tarea | Tiempo |
|-------|--------|
| Plantilla (una vez) | 1-2 horas |
| Cold Storage (58 slides) | 4-5 horas |
| Nodos Bitcoin (56 slides) | 4-5 horas |
| **TOTAL** | **9-12 horas** |

### Atajos de Google Slides que ahorran tiempo
| Atajo | Acción |
|-------|--------|
| Ctrl + D | Duplicar slide (el más útil) |
| Ctrl + Shift + C | Copiar formato |
| Ctrl + Shift + V | Pegar formato |
| Ctrl + M | Nuevo slide |
| Tab | Indentar bullet |
| Ctrl + [ / ] | Más pequeño / más grande |

## 6. Optimización para la Plataforma

### Cómo se ven los slides en Nodo360
Los slides se muestran embebidos en el lesson player. Considera:

- **Resolución:** 16:9 estándar, se escala al ancho del contenedor
- **Móvil:** Se ve más pequeño — texto grande es crítico
- **Interacción:** El usuario pasa slides a su ritmo — cada slide debe ser autocontenido

### Publicar en Google Slides
1. En Google Slides → Archivo → Compartir → "Cualquier persona con el enlace puede ver"
2. Copia la URL
3. En el admin panel de Nodo360, pega la URL en el campo `slides_url` de cada lección

### Organización en Google Drive
```
📁 Nodo360 Slides/
├── 📁 Seguridad Avanzada/
│   ├── 📊 CS-1.1 Hot vs Cold
│   ├── 📊 CS-1.2 Tipos Cold Storage
│   ├── 📊 CS-1.3 Seed Phrases
│   ├── 📊 CS-2.1 Configurar HW Wallet
│   ├── 📊 CS-2.2 Backup Seguro
│   └── 📊 CS-2.3 Verificación Simulacro
├── 📁 Bitcoin Técnico/
│   ├── 📊 NB-1.1 Rol de los Nodos
│   ├── 📊 NB-1.2 Soberanía
│   ├── 📊 NB-1.3 Tipos de Nodos
│   ├── 📊 NB-2.1 Hardware Software
│   ├── 📊 NB-2.2 Instalación
│   └── 📊 NB-2.3 Mantenimiento
```

**¿Un archivo por lección o un archivo por curso?**
- **Un archivo por lección** (recomendado) — más fácil de editar, más ligero, URL independiente
- Un archivo por curso — más compacto pero más difícil de actualizar

## 7. Checklist de Calidad por Slide

Antes de dar por terminado cada slide, verifica:

- [ ] ¿Se entiende en 5 segundos?
- [ ] ¿Solo hay UNA idea principal?
- [ ] ¿El texto es lo suficientemente grande? (mín. 18px)
- [ ] ¿Hay máximo 3 bullets?
- [ ] ¿Los colores son consistentes con la paleta?
- [ ] ¿El contraste es bueno? (texto legible sobre fondo)
- [ ] ¿Hay un elemento visual? (icono, diagrama, emoji)
- [ ] ¿El título es descriptivo?
- [ ] ¿Se ve bien en móvil? (previsualiza)

## 8. Errores Comunes a Evitar

| Error | Solución |
|-------|----------|
| Mucho texto por slide | Máximo 3 bullets de 1 línea |
| Fuentes inconsistentes | Usar solo 1-2 fuentes |
| Colores aleatorios | Ceñirse a la paleta definida |
| Sin jerarquía visual | Título grande → visual → bullets → nota |
| Slides genéricos | Cada slide con propósito claro |
| Perfectionism | Funcional > perfecto. Publica y mejora después |
| Fotos de stock | Usar iconos, diagramas, emojis |
| Fondos blancos | Mantener estética dark mode de Nodo360 |
| Copiar texto completo del lesson player | Los slides complementan, no duplican |
